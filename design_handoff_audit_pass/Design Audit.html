A snappier Liquidity Gate

The current pass is calm, well-tokenized, and fixes the overflow bugs called out in the handoff. It also repeats data, hides primary actions, mixes color semantics, and front-loads chrome that delays the user from seeing what matters. This audit walks through every surface, calls out what to keep, what to collapse, and what to wire up — ending with a proposed condensed layout and a prioritized 4-step roadmap.

Executive summary

Four moves to make it snappier

Each links to detail below.
1 Stop repeating the same stat
Header pills + intake KPI tiles + watch-root counter all carry “23 / 86 obtained.” Pick one source-of-truth surface.
Eliminates ~140px of vertical chrome above the table and gives the eye one place to track progress.
2 Surface the 9 essentials
“9 essential missing” is buried inside a stat tile. It’s the single most actionable number in the app — make it a primary CTA at the top of intake.
One-click filter to the items that actually unblock the next phase. Replaces vague “Add item / Rescan folder” buttons.
3 Unscramble the color semantics
Clay (#c7744f) currently means missing, outflow, and HYSA progress. Three different stories share one accent.
Reassign: clay = expense/outflow only. Use ember for danger/missing, tide for neutral progress.
4 Quiet the chart, raise the signal
Ten floating numbers above bars compete with the bars themselves. Replace with hover-reveal + a single “Net by month” strip beneath.
Lets you fit a 6th panel (trailing 3-mo net trend) in the same row without adding height.

“Local” is implicit — the app is a Tauri desktop binary by design. The year date is shown more usefully in the dashboard’s YTD / 12mo control. Drop the secondary line and use the recovered height to make the tab pills slightly bigger and easier to hit.

Add High Above the checklist

The 9 essential-missing items deserve a primary CTA

Today, “9 essential” is just a tiny caption inside the Missing tile. It’s the answer to “what should I do next?” and it’s smaller than the rescan button. Promote it to a one-line action band — clicking it pre-filters the table to Essential + Missing and scrolls to it.

Remove Medium Top-right actions

“Rescan folder” duplicates the 5-second auto-scan

The watch-root strip already promises Rescans every 5s. A manual rescan button implies that the auto-scan isn’t trustworthy. Either remove the button entirely, or — if there’s a real edge case — demote it to a small icon on the watch-root strip with a tooltip (“Force rescan now”).

Same goes for “Add item” — the README implies the checklist comes from the tracker CSV. If users do sometimes add ad-hoc items, label the button truthfully (“Add custom item”) and move it inside the table’s toolbar where the related context lives.

Collapse Medium Checklist table

“Why needed” column eats 30% width for text users glance at once

The rationale text is genuinely valuable, but it’s read once per document and then forgotten. Collapse it behind a small i button per row, or expose it via row-expand. The reclaimed width lets the document column show matched files inline without truncation — which is where users actually spend their time.

Add Medium Category sidebar

Category sidebar should be the primary filter

Right now the sidebar is read-only — purely informational. It’s perfectly placed to act as a filter rail: click C. Debt & Housing and the table narrows to those 12 items. The “All / Missing / Essential” pill in the table toolbar then composes on top.

Secondary: the single-letter badges (A–I) without a legend feel arbitrary. Either drop them or show the letter at full size and use the long name as a tooltip when truncated.

Fix Low Watch-root strip

Watch-root strip needs a “reveal in Finder” action

The path is shown read-only with monospaced styling, which signals "interactive thing" to most users — but clicking does nothing. Add a small chevron that opens the folder in the OS file manager (you’re in Tauri; shell::open is a one-liner). Also add a copy-path icon. These two affordances together turn the strip from “status” into “tool.”

Collapse Low Page title block

Eyebrow + H1 + sentence is 3 lines for low-density information

On a fully-loaded screen, the eyebrow “Phase 1 · Intake” + H1 “Document checklist” + body sentence eat ~70px without conveying anything actionable. Collapse to “Phase 1 · Intake — Document checklist” as a single 16px section title; move the explanatory sentence behind an info icon, or drop it entirely (the columns explain themselves).

Fix High Inflow/outflow chart

Ten floating numbers above ten thin bars is visual noise

Every bar carries its own value label (e.g. 19.2k) directly above it. At default density the numbers are louder than the bars they describe — and they all hover around the same magnitude (~$17–19k), so reading them doesn’t tell you anything you can’t see from the bar heights. Replace with hover-reveal tooltips, and add a single Net mini-strip beneath the chart so the actually-interesting number (monthly delta) gets its own row.

Fix Medium KPI deltas

“+1.8% vs. Jan” is a misleading delta

Comparing average monthly inflow to a single anchor month (January) hides the actual story. If income drifted up in Feb then back down by May, the “vs. Jan” number can be positive while the trend is negative. Use trailing 3-month vs. prior 3-month (or month-over-month with a sparkline), and label it explicitly: “+1.8% vs. trailing 3-mo”.

Add Medium Leakage

Leakage cards need a drill-down

Today you can see that Amazon spend is 41% over cap, but not which transactions drove it. Add a “See transactions” affordance that pops a side panel listing the underlying entries for the current month — vendor, date, amount, category match score. This turns the dashboard from passive observation into a budget conversation.

Add Low Time-range control

Time-range pills should include a custom range

YTD / 12mo / All covers most needs, but the most common ad-hoc question is "show me April through June." A fourth pill — Custom — opens a small two-month-picker popover.

Section 4

Cross-cutting

4 findings
Add Medium Keyboard

No keyboard surface — and this is a desktop app

Tauri apps live or die by feeling native. Add at minimum: ⌘1 / ⌘2 to switch tabs, ⌘K for a command palette (search docs by name, jump to category, filter to missing), ⌘R to force rescan. A tiny hint cluster in the corner ("⌘K to search") signals the affordance exists.

Add Medium Empty & loading states

Empty states are missing from the mockup

Today the redesign assumes data is present. Define what each surface looks like when: (a) the watch folder doesn’t exist yet, (b) no documents have been matched, (c) the tracker CSV failed to parse, (d) the dashboard has less than one full month of transactions. These are likely your day-one screens — and they’re harder to design than the populated ones.

Fix Low Density

Density is too loose for a power-user financial tool

Many surfaces use p-4 / p-5 on cards holding three rows of content. Drop to p-3 and tighten the gap between rows. The README claims the goal is "compact" — the current spacing reads more like "Notion-comfortable" than "spreadsheet-dense." A user staring at this for an hour wants information density.

Add Low Visual rhythm

All surfaces are bg-white — there’s no figure/ground

Page is paper, every card is white. With nothing tinted, the eye doesn’t know which surface is "primary." Use paper-tint (bg-paper/60) on secondary surfaces — gate strips, leakage cards — and keep pure white for the primary table and chart. Adds rhythm without adding chroma.
